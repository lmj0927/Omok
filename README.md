# 오목 (멀티플레이 게임)

전통적인 보드 게임인 오목을 실시간 멀티플레이어 기능을 갖춘 현대적 구현으로 개발한 프로젝트입니다.

## 게임 개요
오목은 플레이어가 번갈아가며 바둑돌을 놓고, 가로, 세로 또는 대각선으로 5개의 돌을 연속으로 놓는 것이 목표인 전략적 보드 게임입니다. 이 구현은 온라인 멀티플레이어 기능을 갖추고 있어 친구들과 원격으로 게임을 즐길 수 있습니다.

## 기능

- **실시간 멀티플레이**: 친구나 랜덤 상대와 온라인으로 게임을 즐길 수 있습니다
- **제스처 탐지 기능**: 직관적인 돌 놓기 시스템 구현
- **게임 녹화**: 게임 리플레이 시스템을 통해 이전 대전을 저장하고 다시 볼 수 있습니다
- **성능 최적화**: 다양한 기기에서 원활한 게임 플레이 제공
- **오디오 시스템**: 몰입감 있는 사운드 효과와 배경 음악 지원

## 기술적 구현

### 프론트엔드 (Unity)
- Unity 엔진으로 개발
- 직관적인 돌 놓기를 위한 제스처 인식 시스템 구현
- 과거 게임을 다시 볼 수 있는 리플레이 시스템
- 모바일 환경에 최적화된 렌더링

### 백엔드 (Node.js)
- Node.js와 Socket.IO로 구축된 서버
- 플레이어 간 실시간 통신
- JSON 형태로 게임 상태 동기화 프로토콜 구현
- 매치 기록 및 검색 시스템

### 네트워킹
- 안정적인 클라이언트-서버 아키텍처
- 게임 액션 동기화를 위한 커맨드 패턴 사용
- 다양한 네트워크 환경 지원
- 매치 연속성을 위한 세션 관리

### 게임 시스템
- 게임 흐름 제어를 위한 유연한 상태 머신
- UI 및 게임플레이 요소를 위한 이벤트 기반 아키텍처
- 다양한 화면 크기 및 방향에 적응하는 카메라 시스템

## 주요 기술적 성과

- **반응형 터치 컨트롤**: 플레이어의 의도를 정확하게 파악하는 제스처 감지 시스템 개발
- **리플레이 시스템**: 모든 움직임을 포착하고 완전한 재생을 허용하는 포괄적인 게임 녹화 기능 구현
- **성능 최적화**: 효율적인 렌더링과 네트워크 트래픽 관리를 통한 최적의 성능 달성
- **오디오 관리**: 세션 간 지속되는 볼륨 제어 기능이 있는 동적 오디오 시스템 구현

## 개발 도구

- Unity (게임 엔진)
- Node.js (백엔드)
- Socket.IO (실시간 통신)
- C# (프론트엔드 프로그래밍)
- JavaScript (백엔드 프로그래밍)
